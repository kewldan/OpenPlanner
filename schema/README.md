# Схема формата `.oplan`

JSON Schema для `manifest.json` и `model.json` внутри контейнера `.oplan`. Лицензия — MIT (см. `LICENSE` в этой папке), чтобы сторонние инструменты могли свободно читать и писать проекты OpenPlanner.

Описание контейнера: [`docs/architecture.md`](../docs/architecture.md#формат-oplan). Эталонная реализация чтения и записи — крейт [`op-format`](../crates/op-format).
