# Участие в разработке

## Clean room

OpenPlanner повторяет **поведение** существующих планировщиков, но не их код, тексты, иконки и вёрстку.

- Не присылайте код, ассеты, тексты или скриншоты из проприетарных планировщиков.
- Не декомпилируйте, не разбирайте минифицированный JS, не скрейпьте и не автоматизируйте чужие сервисы. Закрытые форматы проектов не разбираем.
- Иконки и условные обозначения рисуем сами (ГОСТ/ЕСКД, IEC).
- Модели и текстуры — только свои, CC0, CC-BY (с атрибуцией) или с совместимой лицензией.
- Новые источники для поведенческой спецификации записывайте в `docs/cleanroom/sources.md`: ссылка, дата, что взято — своими словами.

## Подпись коммитов (DCO)

Подписывайте коммиты (`git commit -s`): так вы подтверждаете [Developer Certificate of Origin](https://developercertificate.org/) — право внести этот код под лицензией проекта.

## Сообщения коммитов

[Conventional Commits](https://www.conventionalcommits.org/ru/): `тип(скоуп): описание`. Скоуп — имя крейта или пакета без префикса: `feat(scan): …`, `fix(model): …`, `docs: …`. Хук `commit-msg` проверяет формат.

## Проверки

Lefthook ставится автоматически при `bun install` и перед коммитом форматирует изменённые файлы. Полные проверки — в CI; локально:

```bash
cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
```

```bash
bunx biome check . && bunx tsc -b && bun test
```
